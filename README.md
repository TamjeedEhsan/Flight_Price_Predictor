# Flight Price Prediction

Machine learning regression project for predicting airline ticket prices using flight and booking features.

## Tech Stack

- Python
- Pandas
- NumPy
- Scikit-learn
- Matplotlib
- Seaborn

## Workflow

- Data cleaning and preprocessing
- Exploratory data analysis
- Feature encoding
- Train/test split
- Random Forest regression
- Model evaluation
- Feature importance
- Hyperparameter tuning

## Dataset

The project uses a dataset containing approximately 300,000 flight records.

## Model

A Random Forest Regressor is used to predict flight prices and evaluated using:

- R²
- MAE
- MSE
- RMSE
